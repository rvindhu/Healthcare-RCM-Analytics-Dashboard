# Healthcare RCM Analytics Dashboard

The Healthcare RCM Analytics Dashboard is a Power BI solution developed to support Revenue Cycle Management by providing actionable insights into claim inventory, accounts receivable, inventory movement, and operational performance.

The dashboard helps stakeholders monitor the current status of claims, identify aged receivables, track inventory trends, and evaluate production performance to support informed business decisions and improve operational efficiency.

## Dashboard Overview

The dashboard consists of four analytical pages, with each page focusing on a different aspect of Revenue Cycle Management:

### 1. Know Your Inventory (KYI)

Provides an overall view of the current claim inventory and helps stakeholders understand the composition and status of the inventory.

### 2. Inventory Trend

Shows how claim inventory moves over time, providing visibility into incoming, pending, and resolved work.

### 3. Current Inventory

Provides a detailed view of the current accounts receivable position, including aging, provider, payer, and claim-status perspectives.

### 4. Production Output

Focuses on operational performance by providing visibility into production, resolution, and overall work completion.
